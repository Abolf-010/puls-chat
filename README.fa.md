# چت بلادرنگ — نمونه کار

یک دموی شاخص از کارهای **بک‌اند / فول‌استک** من: سیستم پیام‌رسانی با دغدغه‌های نزدیک به کار واقعی (realtime، سشن، وضعیت پیام).

تمرکز اصلیم **بک‌اند** است (API، احراز هویت، مدل داده، realtime) و در صورت نیاز فیچرهای **فول‌استک** را هم تا انتها جلو می‌برم. این پروژه ضلع realtime همان مهارت‌ها را نشان می‌دهد — نه تنها پروژه‌ای که بلدم.

## در این دمو چه می‌بینید

- پیام Socket.IO: دلیوری، خوانده‌شدن، تایپینگ
- لیست گفتگوی زنده (آخرین پیام و خوانده‌نشده)
- سیگنالینگ تماس یک‌به‌یک WebRTC
- گروه، مدیا، ویرایش و حذف با UI داخل اپ
- NestJS + MongoDB + Redis + JWT
- کلاینت با رویکرد PWA و رفتار آگاه از آفلاین

## استک

| لایه | تکنولوژی |
|------|-----------|
| بک‌اند | NestJS، TypeScript، MongoDB، Redis، Socket.IO، JWT |
| فرانت | TypeScript (SPA)، دارایی‌های PWA |
| Realtime | روم، کانال کاربر، طراحی مبتنی بر presence |
| تماس | WebRTC (سیگنالینگ روی سوکت؛ کیفیت به شبکه / TURN وابسته است) |

## توضیح صادقانه

کیفیت تماس به مسیر شبکه بستگی دارد. تمرکز این نسخه روی هستهٔ پیام‌رسانی و معماری realtime قابل دفاع است، نه ادعای کلون کامل یک پیام‌رسان بزرگ.

## سازنده

توسعه‌دهنده بک‌اند با تجربه فول‌استک. آماده نقش بک‌اند، کار محصول فول‌استک، و پروژه فریلنس سیستم‌های realtime.
