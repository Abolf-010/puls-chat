# NexaChat — اپلیکیشن پیام‌رسان لحظه‌ای

اپلیکیشن چت فول‌استک با ارتباط لحظه‌ای؛ مناسب ارائه به‌عنوان **نمونه کار** و اجرای لوکال.

> **توجه:** این مخزن عمدتاً به‌صورت سورس‌کد + دموی لوکال ارائه می‌شود. سرور آنلاین دائمی ممکن است در دسترس نباشد (محدودیت میزبانی / شبکه). برای تجربهٔ کامل، پروژه را روی سیستم خودتان اجرا کنید.

---

## قابلیت‌ها (خلاصه)

- پیام‌رسانی **لحظه‌ای** (Socket.IO) — متن، ریپلای، ویرایش، حذف نرم
- رسید **تحویل** و **خوانده‌شدن**
- نشانگر **در حال نوشتن** و وضعیت آنلاین (Redis)
- گفتگوی **خصوصی** و **گروهی**
- رسانه — عکس، ویدیو، ویس، فایل
- تماس صوتی **WebRTC** + تاریخچه تماس
- **PWA** — قابل نصب، شِل آفلاین
- Web Push (اختیاری، با کلید VAPID)
- احراز هویت JWT + رفرش، سشن‌ها، ثبت‌نام / ورود
- پروفایل — نام نمایشی، نام کاربری، بیو، آواتار
- تنظیمات — رمز، سشن‌ها، حریم خصوصی، پوش

## تکنولوژی‌ها

| لایه | فناوری |
|------|--------|
| بک‌اند | NestJS، Socket.IO، MongoDB، Redis |

## راه‌اندازی سریع

```bash
# ۱) نصب وابستگی‌ها
npm ci

# ۲) تنظیم محیط
cp .env.example .env
# مقادیر MONGODB_URI، JWT و REDIS را ویرایش کنید

# ۳) اجرای سرور (فایل‌های public را هم سرو می‌کند)
npm run start:dev

# ۴) باز کردن در مرورگر
# http://localhost:3000/login.html
```

اگر فایل‌های `public/assets/script/*.ts` را تغییر دادید، خروجی JS را دوباره بیلد کنید (tsc یا ابزار بیلد خودتان).

---

## متغیرهای محیطی

فایل **`.env.example`** را ببینید. مهم‌ترین‌ها:

| کلید | کاربرد |
|------|--------|
| `PORT` | پورت HTTP (روی ویندوز ترجیحاً `3000`) |
| `MONGODB_URI` | رشته اتصال مانگو |
| `JWT_SECRET` / `JWT_REFRESH_SECRET` | امضای توکن |
| `REDIS_HOST` / `REDIS_PORT` | حضور آنلاین و کمک‌های realtime |
| `VAPID_*` | پوش مرورگر (اختیاری) |

تولید کلید پوش:

```bash
npx web-push generate-vapid-keys
```

## ساختار کلی پروژه

```
src/                 راه‌اندازی Nest
auth/                ورود، رفرش، گارد JWT
users/               پروفایل و ثبت‌نام
conversations/       چت خصوصی و گروه
messages/            پیام، رسید، آپلود، گیت‌وی
call/                سیگنالینگ تماس و لاگ
presence-redis/      وضعیت آنلاین
push/                اشتراک Web Push
public/              رابط کاربری و PWA
uploads/             فایل کاربران (در گیت نباید باشد)
```
